# ⚡ Launch Kit — 4 Modern HTML Templates

Four clean, responsive, **zero-dependency** website templates you can launch in
minutes. No frameworks, no build step, no npm — just open the files, change the
text and colours, and ship.

Perfect for indie makers, freelancers, and small businesses who need a polished
page *today*.

---

## What's inside

| # | Template | Use it for |
|---|----------|-----------|
| 1 | **Coming Soon / Waitlist** | Pre-launch pages, product waitlists, email capture |
| 2 | **One-Page Portfolio** | Designers, developers, freelancers, creatives |
| 3 | **SaaS / Product Landing** | App launches, products, services, startups |
| 4 | **Local Business One-Pager** | Trades, lawn care, cleaning, cafés, salons — lead-gen with click-to-call |

Each template is its own folder with `index.html`, `style.css`, `script.js`,
and a short README.

## Why you'll like it
- ✅ **Zero dependencies** — no jQuery, no build tools, no package install
- ✅ **Fully responsive** — looks great on phone, tablet, desktop
- ✅ **Light & dark** (portfolio) with remembered preference
- ✅ **Easy rebrand** — every colour is a CSS variable at the top of the file
- ✅ **Accessible & fast** — semantic HTML, reduced-motion support, system fonts + Inter
- ✅ **Deploy free** — drop onto Netlify or GitHub Pages in under a minute

## Quick start
1. Pick a template folder.
2. Open `style.css` → edit the `--accent` colours at the top.
3. Open `index.html` → change the text, title, and links.
4. Double-click `index.html` to preview. Done.

Full per-template instructions (including how to wire up real email capture) are
in each folder's `README.md`.
